# audio_filter

ComfyUI 音频处理节点。目前包含一个节点。

## Audio Harshness Suppressor

去掉录音里扎耳朵的部分——2.5–9 kHz 的齿音嘶声、镲片飞溅、过亮的"存在感"。

**它不是静态 EQ。** 固定高架衰减会把整条轨道变闷；这个节点逐帧测量目标频段，
只在它真正突出来的那些瞬间把它压下去。在合成的元音+周期性 /s/ 语音上实测：
默认参数把齿音压低 **16.9 dB**，而齿音之间的元音段只变化 **1.2 dB**。
在一段真实的 32 kHz 生成音乐上，它把女声抽吸气的刺耳高频压掉 **13.5 dB**，
而正常唱音只动 **0.3 dB**。

### 检测原理

每个 STFT 帧（2048 点 Hann，hop 512）比较目标频段的能量密度与全谱能量密度：

```
tilt_dB = 10*log10(频段密度 / 全谱密度)
```

频谱平坦的信号测得 0 dB，高频自然滚降的信号测得负值。因为是比值，
该数值与输入音量无关，所以 `sensitivity_db` 不需要为每个文件重新标定。

超出 `sensitivity_db` 的部分**线性**映射成 0..1 的驱动量（每多超出 1 dB 就多拿
满衰减的 1/1.5），再用非对称一阶滤波器平滑（上升走 attack，下降走 release），
最后只作为增益曲线乘在频段内的 bin 上。所有声道共用同一条曲线，立体声像不会移动。

频段外的 bin 完全不碰；频段内在非刺耳的帧上增益恒为 1。

**它捕捉的是什么。** 倾斜是一个"当帧占比"量：只有当目标频段占满这一帧的大部分能量时，
数值才会逼近 0。真实情形里这恰好对应**声带让位、只剩明亮噪声**的瞬间——换气声、独立的
/s/、镲片尾音。反过来，混在持续强内容之下的嘶声只会被部分处理（见「已知边界」）。

### 参数

| 输入 | 默认 | 说明 |
| --- | --- | --- |
| `harsh_low_hz` | 2500 | 关注频段下沿。2500 Hz 覆盖存在感与齿音 |
| `harsh_high_hz` | 9000 | 关注频段上沿。收窄到 5000–9000 可只处理齿音 |
| `sensitivity_db` | 0.0 | 频段要比全谱密多少 dB 才动手。平坦信号为 0 dB，越小越激进 |
| `max_reduction_db` | 18.0 | 最刺耳处的最深衰减。设 0 即完全不处理 |
| `attack_ms` | 5.0 | 衰减淡入速度。保持短，才能抓住齿音的起始 |
| `release_ms` | 120.0 | 衰减淡出速度。太短会听出抽吸感（pumping） |
| `mix` | 1.0 | 干湿比，用来 A/B 对比 |

### 调参建议

- 连正常的明亮人声也想压 → `sensitivity_db` 降到 -1 ~ -3（代价见下表）
- 力度不够 → 先提 `max_reduction_db`，**不要**降 `sensitivity_db`
- 只想压人声齿音 → 频段收窄到 5000–9000 Hz
- 听到呼吸/抽吸感 → `release_ms` 提到 250
- 拿不准就先设 `mix=0.5` 对比，再决定

### 默认值是怎么定的

**阈值必须高，力度要靠膝和上限给。** 这是被真实素材打回来才想明白的一点。
在一段 32 kHz 的生成音乐上，分别测抽吸气帧与正常唱音帧的 2.5–4 kHz 衰减：

| `sensitivity_db` | 抽吸气 | 正常唱音 |
| --- | --- | --- |
| **0（默认）** | **-13.48 dB** | **-0.34 dB** |
| -1 | -13.54 dB | -4.30 dB |
| -2 | -13.71 dB | -7.41 dB |
| -3 | -13.86 dB | -9.07 dB |

降 3 dB 阈值只多压抽吸气 0.38 dB，却让唱音多掉 8.7 dB——等于把动态处理器退化成静态 EQ。
第一版默认是 -6 dB / 9 dB / smoothstep，在真实素材上整段平均只衰减 1.27 dB（听不出变化）；
我当时的反应是把阈值一路降到 -12 dB 去换力度，结果唱音被压掉 8.1 dB，而抽吸气只多压 0.6 dB。
正确的做法是**阈值保持在 0 dB（= 频谱平坦这个与素材无关的锚点），力度交给窄膝和 18 dB 上限**。

**检测器的判别力**。在同一素材上，抽吸气帧与唱音帧的倾斜几乎不重叠：

| | 倾斜 p90 | 倾斜 max |
| --- | --- | --- |
| 抽吸气 | +1.70 dB | +2.42 dB |
| 正常唱音 | -10.28 dB | -1.51 dB |

在合成的「元音 + 周期性 /s/」信号上（517 帧，齿音帧 72）扫阈值，误报率/命中率：

| `sensitivity_db` | 非齿音帧误报 | 齿音帧命中 |
| --- | --- | --- |
| -6 | 2.7% | 98.6% |
| **0（默认）** | **2.0%** | **90.3%** |
| +2 | 1.8% | 75.0% |
| +4 | 1.1% | 58.3% |

检测量本身也在四种候选（频段/全谱倾斜、频段/带外密度、频带电平对自身慢平均、
倾斜对自身慢平均）中比过：时域参考方案分离度只有 2.3 dB，被排除；
频段/带外密度判别力与所选方案等价，但取值无界，阈值跨素材更不稳定，因此未采用。
另外试过两条都不成立的路：**平坦度（噪声性）门控**在抽吸气与唱音上分布基本重叠
（p50 0.040 vs 0.034），**逐带局部包络（谱峰）检测**的驱动比是 1.0x，即完全无选择性。

### 已知边界

- **混在持续强内容下的嘶声只会被部分处理。** 检测器要求目标频段在当帧占主导；
  如果人声/伴奏一直很强，倾斜上不去，衰减就有限。此时把 `sensitivity_db` 降到
  -1 ~ -3 可以抓到，代价是同时压暗正常内容。
- 只管高频刺耳。爆音/咔哒/电流声属于瞬态问题，不在范围内。
- **窄带纯音**（例如单独一个 6.5 kHz 正弦）如果与低频内容同时存在且能量相当，
  频段密度不足以越过阈值，不会被处理。它针对的是密集/噪声性的刺耳。
- 低频刺痛（鼻音、轰隆）不在范围内——检测量是全谱倾斜。

## 安装

放进 `ComfyUI/custom_nodes/` 后重启 ComfyUI。无额外依赖，只用已经装好的 PyTorch。

## 测试

核心算法 `dsp.py` 不依赖 ComfyUI，可以脱离服务端直接跑：

```
python tests/test_dsp.py
```

覆盖：形状/ dtype 保持、刺耳段被压而其余部分不动、频段选择、声道联动、
0 衰减透明、0 干湿比直通、静音、极短片段（1 采样）、退化频段、
attack/release 时间常数、批内独立、以及耗时（60 秒立体声约 0.15 秒）。
