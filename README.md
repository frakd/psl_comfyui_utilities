# audio_filter

ComfyUI 音频处理节点。目前包含一个节点。

## Audio Harshness Suppressor

去掉录音里扎耳朵的部分——齿音嘶声、镲片飞溅、以及过亮的高频"存在感"。

**它不是静态 EQ。** 固定高架衰减会把整条轨道变闷；这个节点逐帧测量目标频段，
只在它真正突出来的那些瞬间把它压下去。在一段真实的 32 kHz 生成音乐上实测：
默认参数把女声上滑到高音时的刺耳感压掉 **15.5–17.1 dB**，
而正常唱音在同一频段只变化 **4.5 dB**。

### 检测原理

每个 STFT 帧（2048 点 Hann，hop 512）比较目标频段的能量密度与全谱能量密度：

```
tilt_dB = 10*log10(频段密度 / 全谱密度)
```

频谱平坦的信号测得 0 dB，高频自然滚降的信号测得负值。因为是比值，
该数值与输入音量无关，所以 `sensitivity_db` 不需要为每个文件重新标定。

超出 `sensitivity_db` 的部分**线性**映射成 0..1 的驱动量（每多超出 1 dB 就多拿
满衰减的 1/1.5），再用非对称一阶滤波器平滑（上升走 attack，下降走 release），
最后只作为增益曲线乘在频段内的 bin 上。所有声道共用同一条曲线，立体声像不会移动。

频段外的 bin 完全不碰；频段内在非刺耳的帧上增益恒为 1。

### 参数

| 输入 | 默认 | 说明 |
| --- | --- | --- |
| `harsh_low_hz` | 5500 | 关注频段下沿。这是齿音与高频刺耳的下界 |
| `harsh_high_hz` | 14000 | 关注频段上沿。16 kHz 采样率的一半附近一般已无内容 |
| `sensitivity_db` | -12.0 | 频段要比全谱密多少 dB 才动手。平坦信号为 0 dB，越小越激进 |
| `max_reduction_db` | 18.0 | 最刺耳处的最深衰减。设 0 即完全不处理 |
| `attack_ms` | 5.0 | 衰减淡入速度。保持短，才能抓住刺耳的起始 |
| `release_ms` | 120.0 | 衰减淡出速度。太短会听出抽吸感（pumping） |
| `mix` | 1.0 | 干湿比，用来 A/B 对比 |

### 调参建议

- 只想处理最高频的嘶嘶声 → 下沿提到 8000–9000
- 觉得压得不够 → 先把 `max_reduction_db` 提到 24，**不要**动 `sensitivity_db`
- 觉得正常内容也被压暗 → `sensitivity_db` 提到 -6，或 `harsh_low_hz` 提到 7000
- 连中频也要处理（鼻音、2–4 kHz 的硬感）→ 下沿降到 2000，但注意这很容易把整轨压暗
- 听到呼吸/抽吸感 → `release_ms` 提到 250
- 拿不准就先设 `mix=0.5` 对比，再决定

### 默认值是怎么定的

**频段与阈值必须一起定，缺一个都不行。** 这份素材上，刺耳感出现在女声从低音
突然上滑到高音的那一瞬（t≈12.9–13.4 s）。逐项实测：

| 频段 / 阈值 | 刺耳段 6–9 kHz | 刺耳段 9–14 kHz | 正常唱音 6–14 kHz |
| --- | --- | --- | --- |
| 2500–9000 / 0 dB（旧默认） | 0.00 | 0.00 | 0.00 |
| 2500–14000 / 0 dB | -0.01 | -0.01 | -0.19 |
| 6000–14000 / -12 dB | -11.20 | -14.66 | -4.11 |
| **5500–14000 / -12 dB（默认）** | **-15.53** | **-17.05** | **-4.48** |
| 5000–14000 / -14 dB | -17.99 | -17.99 | -5.84 |

两处关键结论：

1. **旧默认（上限 9 kHz）在这段完全不触发**——实测输出与输入逐位相同。
   刺耳能量主要在 10–12 kHz，而它不在监控范围内。
2. **光把频段加宽没用**（第二行仍是 0.00 dB）。真正的判别量是"目标频段相对全谱的密度"，
   阈值必须一起放到 -12 才会响应。宽度与阈值是耦合的，不能单独调一个。

**判别力**：该素材上各候选统计量的分离度（刺耳段中位数 − 正常唱音 p90）：

| 统计量 | 分离度 |
| --- | --- |
| **6–14 kHz 倾斜（所采用）** | **+3.17 dB** |
| 6–14 kHz 能量 / 全谱能量 | +4.03 dB |
| 4–6 kHz 倾斜 | -1.89 dB（无分离）|

4–6 kHz 没有分离度，这也是下沿取 5500 而不是 4000 的原因。

**合成信号上的表现**（元音 + 周期性 /s/，517 帧，齿音帧 72）：

| `sensitivity_db` | 非齿音帧误报 | 齿音帧命中 |
| --- | --- | --- |
| -6 | 2.5% | 98.6% |
| **-12（默认）** | **3.6%** | **98.6%** |
| -18 | 4.3% | 100.0% |

误报率在 -6 到 -18 之间只从 2.5% 升到 4.3%，说明判别力稳，阈值不需要精调。

### 走过的弯路（留档，避免重犯）

- **用缓入曲线换"自然"**：smoothstep 让刚过阈值的帧衰减接近 0，
  真实素材整段平均只衰减 1.27 dB，听不出任何变化。
- **用降阈值换力度**：把阈值从 -6 降到 -12 后，抽吸气只多压 0.6 dB，
  正常唱音却多掉 8.1 dB——动态处理器退化成静态 EQ。
- **用噪声性（谱平坦度）做门控**：抽吸气与唱音的平坦度分布基本重叠
  （p50 0.040 vs 0.034），完全不成立。
- **用逐带局部包络（谱峰）检测**：驱动比 1.0x，即完全没有选择性，
  因为唱音的谐波峰相对谐波间谷底同样是"凸起"。
- **靠基频轨迹定位**：自相关追踪器在快速上滑处饱和，给出的时间窗是错的，
  最后是靠听者反馈 + 谱质心才定位准确。

### 已知边界

- **它不是"任何刺耳都能去掉"。** 要求目标频段在当帧足够突出；如果刺耳内容一直混在
  更强的中低频里，倾斜上不去，衰减就有限。此时降低 `sensitivity_db` 可以抓到，
  代价是同时压暗正常内容。
- **非线性伪影（混叠、量化、模型生成痕迹）不在能力范围内。** 这类问题表现为
  "能量出现在错误的、非谐波的位置"，不是某个频段能量偏多，减法 EQ 无法修复。
  这类素材把高频整段切掉后往往仍会残留一层"粗粒感"。
- 爆音/咔哒/电流声属于瞬态问题，不在范围内。
- 窄带纯音（例如单独一个 6.5 kHz 正弦与低频能量相当）不会被处理。
- 低频刺痛（鼻音、轰隆）不在范围内。

## 安装

放进 `ComfyUI/custom_nodes/` 后重启 ComfyUI。无额外依赖，只用已经装好的 PyTorch。

## 测试

核心算法 `dsp.py` 不依赖 ComfyUI，可以脱离服务端直接跑：

```
python tests/test_dsp.py
```

覆盖：形状/dtype 保持、刺耳段被压而其余部分不动、频段选择、声道联动、
0 衰减透明、0 干湿比直通、静音、极短片段（1 采样）、退化频段、
attack/release 时间常数、批内独立、偏暖素材不被过度处理、
抽吸气被深压而唱音不动，以及耗时（60 秒立体声约 0.13 秒）。
