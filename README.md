# audio_filter

ComfyUI 音频处理节点。目前包含一个节点。

## Audio Harshness Suppressor

去掉录音里扎耳朵的部分——2.5–9 kHz 的齿音嘶声、镲片飞溅、过亮的"存在感"。

**它不是静态 EQ。** 固定高架衰减会把整条轨道变闷；这个节点逐帧测量目标频段，
只在它真正突出来的那些瞬间把它压下去。在合成的元音+周期性 /s/ 语音上实测：
默认参数把齿音压低 **11.9 dB**，而齿音之间的元音段只变化 **1.0 dB**。

### 检测原理

每个 STFT 帧（2048 点 Hann，hop 512）比较目标频段的能量密度与全谱能量密度：

```
tilt_dB = 10*log10(频段密度 / 全谱密度)
```

频谱平坦的信号测得 0 dB，高频自然滚降的信号测得负值。因为是比值，
该数值与输入音量无关，所以 `sensitivity_db` 不需要为每个文件重新标定。

超出 `sensitivity_db` 的部分**线性**映射成 0..1 的驱动量（每多超出 1 dB 就多拿
`1/6` 的满衰减），再用非对称一阶滤波器平滑（上升走 attack，下降走 release），
最后只作为增益曲线乘在频段内的 bin 上。所有声道共用同一条曲线，立体声像不会移动。

频段外的 bin 完全不碰；频段内在非刺耳的帧上增益恒为 1。

> 响应曲线曾经是 smoothstep（缓入缓出），在合成语音上标定时看着很好，但换到真实
> 素材就失效了：真实素材的倾斜值绝大多数只比阈值高一点，缓入曲线把那些帧的衰减
> 压到接近 0，实测整段平均只衰减 1.27 dB，等于没效果。改成线性后同一素材是 3.6 dB。

### 参数

| 输入 | 默认 | 说明 |
| --- | --- | --- |
| `harsh_low_hz` | 2500 | 关注频段下沿。2500 Hz 覆盖存在感与齿音 |
| `harsh_high_hz` | 9000 | 关注频段上沿。收窄到 5000–9000 可只处理齿音 |
| `sensitivity_db` | -12.0 | 频段要高出全谱多少 dB 才动手。平坦信号为 0 dB，越小越激进 |
| `max_reduction_db` | 12.0 | 最刺耳处的最深衰减。设 0 即完全不处理 |
| `attack_ms` | 5.0 | 衰减淡入速度。保持短，才能抓住齿音的起始 |
| `release_ms` | 120.0 | 衰减淡出速度。太短会听出抽吸感（pumping） |
| `mix` | 1.0 | 干湿比，用来 A/B 对比 |

### 调参建议

- 处理完觉得变闷 → 把 `sensitivity_db` 往 0 提（例如 -8），或把 `max_reduction_db` 降到 8
- 力度不够 → `sensitivity_db` 往 -16 走，`max_reduction_db` 提到 15
- 只想压人声齿音 → 频段收窄到 5000–9000 Hz
- 整轨都亮/都刺（EDM、失真吉他）→ 放宽到 2000–12000 Hz
- 听到呼吸/抽吸感 → `release_ms` 提到 250
- 拿不准就先设 `mix=0.5` 对比，再决定

### 默认值是怎么定的

**检测器**：在合成的「元音 + 周期性 /s/」信号上扫阈值（517 帧，其中齿音帧 72），
得到各阈值下的误报率（非齿音帧被判为刺耳的比例）与命中率：

| `sensitivity_db` | 非齿音帧误报 | 齿音帧命中 |
| --- | --- | --- |
| -18 | 97.5% | 100.0% |
| **-12（默认）** | **4.9%** | **100.0%** |
| -6 | 2.7% | 98.6% |
| 0 | 2.0% | 90.3% |

同一信号加上高频架衰减后，行为随素材亮度正确变化（齿音段始终被压 -11.85 dB）：

| 高频架 | 元音段被压 |
| --- | --- |
| -6 dB（偏暖） | -0.93 dB |
| 0 dB | -1.00 dB |
| +9 dB（偏亮） | -9.68 dB |
| +15 dB | -11.96 dB |

即：暖素材只压齿音、几乎不碰元音；亮素材则整段都在被压——因为它确实刺耳。
这两条行为各有一个测试守着（`test_warm_material_is_left_alone`、
`test_bright_material_is_cut_deeply`）。

检测量本身也在四种候选（频段/全谱倾斜、频段/带外密度、频带电平对自身慢平均、
倾斜对自身慢平均）中比过：时域参考方案分离度只有 2.3 dB，被排除；
频段/带外密度判别力与所选方案等价，但取值无界，阈值跨素材更不稳定，因此未采用。

**力度**：默认力度不是算出来的，是被真实素材打回来改的。第一版用 -6 dB / 9 dB /
smoothstep，在一段 32 kHz 的生成音乐上整段平均只衰减 1.27 dB，听不出任何变化；
逐帧拆解后发现倾斜分布在触发区的值只比阈值高一点点，而被缓入曲线抹平。
改成线性响应并把默认提到 -12 dB / 12 dB 后，同一素材在 3–9 kHz 上衰减 7–10.8 dB，
而合成语音上的齿音/元音比反而更好（11.9 dB vs 1.0 dB）。

### 已知边界

- 只管高频刺耳。爆音/咔哒/电流声属于瞬态问题，嘶嘶底噪属于宽带噪声，都不在范围内。
- 低频刺痛（鼻音、轰隆）不在范围内——频段下沿最低只到 200 Hz，但检测量是全谱倾斜。
- 假定刺耳表现为频谱倾斜。若刺耳只集中在很窄的一个共振峰上、而频段其余部分干净，
  检测量会被稀释。

## 安装

放进 `ComfyUI/custom_nodes/` 后重启 ComfyUI。无额外依赖，只用已经装好的 PyTorch。

## 测试

核心算法 `dsp.py` 不依赖 ComfyUI，可以脱离服务端直接跑：

```
python tests/test_dsp.py
```

覆盖：形状/ dtype 保持、刺耳段被压而其余部分不动、频段选择、声道联动、
0 衰减透明、0 干湿比直通、静音、极短片段（1 采样）、退化频段、
attack/release 时间常数、批内独立、以及耗时（60 秒立体声约 0.15 秒）。
