# audio_filter

ComfyUI 音频处理节点。目前包含一个节点。

## Audio Harshness Suppressor

去掉录音里扎耳朵的部分——2.5–9 kHz 的齿音嘶声、镲片飞溅、过亮的"存在感"。

**它不是静态 EQ。** 固定高架衰减会把整条轨道变闷；这个节点逐帧测量目标频段，
只在它真正突出来的那些瞬间把它压下去。在合成的元音+周期性 /s/ 语音上实测：
默认参数把齿音压低 **8.9 dB**，而齿音之间的元音段只变化 **0.7 dB**。

### 检测原理

每个 STFT 帧（2048 点 Hann，hop 512）比较目标频段的能量密度与全谱能量密度：

```
tilt_dB = 10*log10(频段密度 / 全谱密度)
```

频谱平坦的信号测得 0 dB，高频自然滚降的信号测得负值。因为是比值，
该数值与输入音量无关，所以 `sensitivity_db` 不需要为每个文件重新标定。

超出 `sensitivity_db` 的部分经 6 dB 软膝映射成 0..1 的驱动量，用非对称一阶滤波器
平滑（上升走 attack，下降走 release），最后只作为增益曲线乘在频段内的 bin 上。
所有声道共用同一条曲线，立体声像不会移动。

频段外的 bin 完全不碰；频段内在非刺耳的帧上增益恒为 1。

### 参数

| 输入 | 默认 | 说明 |
| --- | --- | --- |
| `harsh_low_hz` | 2500 | 关注频段下沿。2500 Hz 覆盖存在感与齿音 |
| `harsh_high_hz` | 9000 | 关注频段上沿。收窄到 5000–9000 可只处理齿音 |
| `sensitivity_db` | -6.0 | 频段要高出全谱多少 dB 才动手。平坦信号为 0 dB，越小越激进 |
| `max_reduction_db` | 9.0 | 最刺耳处的最深衰减。设 0 即完全不处理 |
| `attack_ms` | 5.0 | 衰减淡入速度。保持短，才能抓住齿音的起始 |
| `release_ms` | 120.0 | 衰减淡出速度。太短会听出抽吸感（pumping） |
| `mix` | 1.0 | 干湿比，用来 A/B 对比 |

### 调参建议

- 处理完觉得变闷 → 把 `sensitivity_db` 往 0 提（例如 -3）
- 只想压人声齿音 → 频段收窄到 5000–9000 Hz
- 整轨都亮/都刺（EDM、失真吉他）→ 放宽到 2000–12000 Hz，`max_reduction_db` 提到 12
- 听到呼吸/抽吸感 → `release_ms` 提到 250
- 拿不准就先设 `mix=0.5` 对比，再决定

### 默认值是怎么定的

在合成的「元音 + 周期性 /s/」信号上扫阈值，得到各阈值下的误报率
（非齿音帧被处理的比例）与命中率：

| `sensitivity_db` | 非齿音帧误报 | 齿音帧命中 |
| --- | --- | --- |
| -12 | 3.1% | 96.2% |
| **-6（默认）** | **2.2%** | **88.5%** |
| 0 | 1.5% | 54.8% |

同一 -6 dB 阈值在给该信号加 -6 dB 高频架衰减后完全不出手，加 +9 dB 高频架后
则持续出手——这正是期望行为。检测量本身也在四种候选（频段/全谱倾斜、
频段/带外密度、频带电平对自身慢平均、倾斜对自身慢平均）中比过：另一种
时域参考方案分离度只有 2.3 dB，被排除；频段/带外密度判别力与所选方案等价，
但取值无界，阈值跨素材更不稳定，因此未采用。

### 已知边界

- 只管高频刺耳。爆音/咔哒/电流声属于瞬态问题，嘶嘶底噪属于宽带噪声，都不在范围内。
- 低频刺痛（鼻音、轰隆）不在范围内——频段下沿最低只到 200 Hz，但检测量是全谱倾斜。
- 假定刺耳表现为频谱倾斜。若刺耳只集中在很窄的一个共振峰上、而频段其余部分干净，
  检测量会被稀释。

## 安装

放进 `ComfyUI/custom_nodes/` 后重启 ComfyUI。无额外依赖，只用已经装好的 PyTorch。

## 测试

核心算法 `dsp.py` 不依赖 ComfyUI，可以脱离服务端直接跑：

```
python tests/test_dsp.py
```

覆盖：形状/ dtype 保持、刺耳段被压而其余部分不动、频段选择、声道联动、
0 衰减透明、0 干湿比直通、静音、极短片段（1 采样）、退化频段、
attack/release 时间常数、批内独立、以及耗时（60 秒立体声约 0.15 秒）。
